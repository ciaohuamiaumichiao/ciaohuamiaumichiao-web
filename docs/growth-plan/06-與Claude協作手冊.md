# 06 與 Claude 協作手冊

> 你是主角、導演、最後的判斷者。我是副導演＋編輯＋策略夥伴＋紀錄者。
> 就像你的導演起始包說的：「幫你做粗活，但不會搶你的判斷。」

## 一、我們的分工

| 你負責 | Claude 負責 |
|---|---|
| 提供素材（錄音、逐字稿、一段經驗、照片、案子） | 整理成文章初稿、腳本、Shorts 時間碼、carousel、Threads、電子報 |
| 面對鏡頭、說你真正想說的話 | 準備提詞重點、HOOK 選項、標題 A/B |
| 決定「要不要」「對不對」 | 提供 2–3 個選項與理由，不替你決定 |
| 每週回顧時誠實打分 | 對照計畫，提醒進度、指出模式、調整下週 |
| 守住信仰與價值的底線 | 檢查內容有沒有偏離定位、有沒有業配腔 |

## 二、你可以直接丟給我的指令（在這個 repo 開 Claude Code 就能用）

複製貼上，換掉中括號就好：

### 內容生產
- **「素材變八份」**：`這是 [錄音逐字稿／一段經驗]，照 docs/growth-plan/02 的一源多用流水線，產出文章初稿、YT 腳本、3 支 Shorts 時間碼、IG carousel、3 則 Threads。`
- **「文章變腳本」**：`把 content/writing/[檔名].md 改成 YT 長片腳本，格式照 content/_sources/youtube/01_photography-is-feeling_script.md。`
- **「下標題」**：`這支片的主題是 [ ]，給我 5 個標題和 3 個縮圖文字，照我網站文章的標題風格。`
- **「寫電子報」**：`整理這兩週發佈的文章和影片，寫一封電子報，語氣照創刊號。`

### 規劃與回顧
- **「週會」**（每週一）：`週會。看 docs/growth-plan/03 和上週的回顧，告訴我這週要做的 3 件事。`
- **「週回顧」**（每週日）：`週回顧：身體 [ ] 靈 [ ] 創作 [ ] 關係 [ ] 財務 [ ]，這週發了 [ ]，亮著的時刻是 [ ]，卡住的是 [ ]。` → 我會寫進 `reviews/` 並更新計畫。
- **「月報」**：`月報，這是 YouTube Studio／Substack 的數字：[ ]。`

### 收入與產品
- **「這能變產品嗎」**：`我剛結案 [案子]，流程是 [ ]，這能不能變成模板或產品？`
- **「工具實測頁」**：`我用了 [工具] [多久]，帳單／心得是 [ ]，幫我做一頁 /tools/[名稱]，格式照 Higgsfield 那頁。`

### 誠實的提醒
- **「我卡住了」**：`我這週不想錄，原因是 [ ]。` → 我不會叫你硬撐，會一起找出最小可行的一步，或建議直接跳過。

## 三、我們之間的約定

1. **你的聲音優先**：所有文案都要用你網站文章的口吻（口語、自嘲、先講故事）。如果我寫得像行銷文，直接退件。
2. **事實要對**：引用人名、數字、教會名稱前我會標「待確認」（像 KUA 逐字稿 README 那樣）。涉及他人隱私的內容，發表前去識別。
3. **計畫是活的**：每次回顧後，我會直接修改這個資料夾的文件並 commit，你可以從 git 歷史看到計畫怎麼長大。
4. **祝福先於成長，成長先於收入**：當三者衝突時，照這個順序決定。
