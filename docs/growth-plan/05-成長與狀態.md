# 05 成長與狀態

> 「41 歲了，我還是不知道自己要成為誰耶。」——你在 3 月寫的。
> 這份文件不是要幫你回答那個問題，而是陪你在做的過程中，慢慢看見答案。

## 一、為什麼要有這份文件

你現在同時在跑：兩檔週更節目、紀錄片、直播、教課、陪跑客戶、社群、網站、聖誕遊行。再加一個 YouTube 頻道，**最大的風險不是失敗，是燒掉**。

而且你在文章裡已經說過：「罵自己的那一段，其實比想不出來還糟」、「站在器材前面就是不想動」。所以我們要有一個機制，在你累之前先看見。

## 你的性格怎麼影響這件事（ENFP-T・九型 4 號）

你在 Threads 簡介寫了自己是 ENFP-T、九型人格 4 號。這不是診斷，只是拿來設計一個適合你的計畫：

- **4 號重視「真實、獨特、有感覺」** → 所以計畫裡不放模仿別人的爆款公式，用你自己的故事和口吻。也要小心：4 號容易拿自己跟別人比、覺得「我做的還不夠特別」。→ 月報只跟上個月的自己比。
- **ENFP 點子很多、容易開新線** → 你已經開了很多條線。新點子先寫進 `ideas.md`，90 天內不開新坑。
- **-T（turbulent）對自己要求高、情緒起伏大** → 防燒毀守則（第五節）對你特別重要。
- **不想剪輯** → 這很合理：你的天賦在「感受」與「判斷」，不在重複的機械操作。把剪輯交出去不是偷懶，是把自己放在對的位置。

## 二、個人狀態儀表板（五個面向）

每週日用 1–5 分評一次，不用解釋，憑感覺：

| 面向 | 問自己 | 照顧方式 |
|---|---|---|
| 🫀 **身體** | 睡得夠嗎？有動嗎？眼睛還好嗎？ | 健身（硬舉）、跑步（跑者肌地讓你有現成的理由）、術後的眼睛 |
| 🕊 **靈** | 這週有沒有「爸爸，你要我做什麼」的時刻？ | 安息日、個人靈修、不是為了服事的敬拜 |
| 🎬 **創作** | 這週有沒有一刻「整個人是亮著的」？（音控台那天的感覺） | 至少一件不為客戶、不為頻道的創作 |
| 🤝 **關係** | 跟太太、家人、朋友有沒有好好在一起？ | 「你的收入是身邊五個朋友的中位數」→ 刻意經營幾個讓你變好的關係 |
| 💰 **財務** | 現金流安心嗎？非接案收入有沒有在長？ | 月報看一次就好 |

**警戒線**：任兩項連續兩週 ≤ 2 分 → 下一週頻道自動降到最低節奏（只發 Threads），不用跟任何人交代。

## 三、學習路線（你在這個專案裡會長出的能力）

| 能力 | 為什麼 | 怎麼學 |
|---|---|---|
| **面對鏡頭說話** | 30 年在幕後，這是最大的跨越 | 前 10 支片就是練習；看自己的片，每支只改一件事 |
| **數據判讀** | 知道什麼內容真的在祝福人 | 月報時一起看 YouTube Studio 的「觀眾留存」與「留言」 |
| **產品化思維** | 從「一次一案」到「做一次、用很多次」 | 每次結案問：這能不能變模板？ |
| **說「不」** | 時間是你最稀缺的資源 | 每個新邀約先對照四個支柱：不在裡面的，優先婉拒 |
| **AI 協作系統** | 你已經是先行者，把它變成你的槓桿 | 持續更新導演起始包，讓自己的工作流就是產品 |

## 四、成長的里程碑（不是數字，是故事）

- [ ] 第一次看自己的影片，沒有想要整支重剪
- [ ] 第一次收到陌生人說「我照你說的做了」
- [ ] 第一次有教會說「我們用了你的模板，排班不吵架了」
- [ ] 第一次在睡覺的時候有錢進來
- [ ] 第一次有人說「我是看你的頻道才開始做幕後的」
- [ ] 能用一句話說出「我要成為誰」（不急）

## 五、防燒毀守則

1. **週六安息**，不剪、不發、不看數據。
2. **錄影日不接案**。
3. **每季一週「空檔週」**：頻道只發預錄好的內容。
4. **感到在湊內容時，跳過那一週**——就像你對電子報讀者的承諾：「如果哪天我發現自己在湊字數，我會直接跳過那個月。」對自己也一樣。
