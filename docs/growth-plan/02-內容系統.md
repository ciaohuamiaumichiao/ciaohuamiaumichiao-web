原則：**不另外開一條生產線，而是讓你本來就在做的工作，自動長出內容。**

        │         │

        │                   │
        │                   └──► ⑤ 3 支 Shorts（Claude 標時間碼，你或助理剪）

## 五、品牌一致性

- **開場固定句**（建議）：「我是小花，做了 30 年幕後，今天想跟你聊⋯⋯」
- **視覺**：沿用網站的「場記板／Tally 燈」語彙（紅色 LIVE、藍綠 STANDBY），片頭 3 秒場記板。
- **語氣**：網站文章的口吻就是你的品牌——「啊」「耶」「喔」、自嘲、先講故事再講道理。不要變成業配腔。
- **標題公式**：具體場景 + 反差（「有人請我教他兒子攝影，我拒絕了」）。你的文章標題已經寫得很好，直接用。
