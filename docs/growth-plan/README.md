## 一句話

**「30 年的幕後人，終於走到鏡頭前，把『看見』這件事教給每一個不出聲的人。」**

你不需要變成另一個人才能當 YouTuber。你已經有 15 年作品、20 年教會服事、兩檔週更節目、一部即將首映的紀錄片、37 篇文章。缺的不是內容，是**一套讓內容固定被看見、並且會自己長大的系統**。

## 三個目標，同一條路

| 目標 | 意思 | 我們怎麼量 |
|---|---|---|
| 🙏 **成為祝福** | 你的內容讓「幕後人」「不出聲的敬拜者」「想拍自己故事的小團體」真的被幫到 | 留言／私訊裡「我照著做了」的故事數、免費資源下載數、陪伴的團體數 |
| 🌱 **學習與成長** | 你在這個過程裡變成更完整的人：身體、信仰、創作、關係都照顧到 | 每週回顧（見 `05-成長與狀態.md`），不是看數字，是看你有沒有「亮著」 |
| 💰 **被動收入** | 收入不再 100% 綁在你的工時上 | 非接案收入佔比：先拿到第一筆 → 每月 NT$10,000 → 每月 NT$50,000 |

順序很重要：**先祝福，再成長，收入是結果**。這不是口號，是策略——在這個時代，信任是唯一換不掉的東西，而信任來自你先給。
